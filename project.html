Fraud Analysis in Indian Consumer Transactions

A Power BI dashboard exploring fraud patterns, transaction trends, and geographic insights across 10K+ Indian consumer records.

Overview

This project analyzes over 10,000 consumer transactions across India to uncover fraud trends, high-risk categories, and state-level spending behavior. It demonstrates the full process — from Python-based data cleaning to an interactive Power BI dashboard that communicates key insights clearly and visually.

Tools & Process

  • Python (pandas, numpy): data cleaning, missing value handling, and feature engineering
  • Power BI Desktop: DAX measures, calculated columns, KPI design, and custom visuals
  • Git & GitHub: version control and documentation

Key KPIs

  • Total Transactions: 10.27K
  • Fraudulent Transactions: 5,046
  • Fraud Rate: 52.44%
  • Average Fraud Amount: ₹5.10K
  • Average Revenue per Customer: ₹51.82K

Visual Highlights

  • Fraud Trend Over Time: Dual-axis chart showing spikes in fraudulent transactions during Oct–Dec.
  • Fraud vs Legitimate Split: Donut chart visualizing the proportion of fraudulent activity across all transactions.
  • Fraud Rate by Category: Bar chart highlighting Online Shopping and Entertainment as high-risk categories.
  • Fraud Amount by State: Map showing high-value fraud clusters in Maharashtra, Karnataka, and Tamil Nadu.
  • Fraud by Transaction Value: Histogram revealing that most fraud occurs in low to mid-value (<₹10K) ranges.

Insights

The dashboard highlights how fraud disproportionately affects digital-heavy categories, with activity peaking during high-spending periods. While low-value transactions dominate in frequency, high-value frauds contribute significantly to overall financial loss. The geographical layer reveals fraud concentration in high-income states, emphasizing the need for targeted monitoring.

Outcome

The final dashboard provides a unified fraud intelligence view — helping stakeholders identify patterns, assess monetary risk, and understand how geography and category influence fraudulent activity. It demonstrates my ability to design data pipelines, perform quantitative analysis, and translate findings into clear visual narratives.
